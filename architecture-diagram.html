Banking RAG Chatbot Architecture

Local FAQ Knowledge System | Semantic Retrieval + LLM Generation

Security Controls

  • • Rate limiting to prevent abuse
  • • Input validation and PII detection
  • • Prompt injection filtering
  • • No real customer data in v1
  • • Session isolation per user

Performance Targets

  • • P50 query latency: < 2s
  • • P99 query latency: < 5s
  • • Concurrent users: 10+ local
  • • Index size: Up to 10K documents
  • • Context window: 4K-8K tokens

Data Flow

  • • Query → Security → Intent Router
  • • Hybrid Retrieval (dense + sparse)
  • • Reranking (Top-K refinement)
  • • Context Assembly → LLM Prompt
  • • Grounded Generation → Citation

Compliance Boundaries

  • • FAQ system only - no transactions
  • • No balance/payment/card operations
  • • No customer authentication (demo)
  • • Knowledge-base answers only
  • • Clear abstention on unknown queries
